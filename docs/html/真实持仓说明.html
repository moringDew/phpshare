真实持仓录入说明

告诉我这些信息即可

  • 买入或卖出方向。

  • 股票代码；股票名称可一起提供，仅有名称时先确认对应代码。

  • 实际成交日期和时间，默认为北京时间。

  • 成交价格、成交金额。

  • 成交股数（能由金额和价格准确推算时可省略）。

  • 手续费及金额是否包含费用；不知道手续费时会标记为未知。

格式示例（仅为格式，不会自动录入）：

买入 600000 浦发银行，2026-11-13 14:50，成交价 10 元，成交金额 10000 元，手续费另计 5 元。

卖出也按相同格式告知。只有你确认实际成交后才登记，策略提醒和计划不作为成交。

台账和盈亏

真实成交与策略模拟盘分开保存。多次买入按移动加权平均成本合并，部分卖出扣除相应成本并计算已实现盈亏。

已知买入费用计入成本，卖出费用扣减已实现盈亏；未提供费用时显示“未知”，不把零费用当成已确认事实。没有初始资金、资金转入转出和分红记录时，不计算账户现金余额及总收益率。

当前只记录实际成交和已实现盈亏。没有真实未复权行情时，不用模拟回测的复权价格估算实盘市值、浮动盈亏或实盘止损。

与微信提醒的关系

已有买卖提醒仍按策略模拟盘生成。录入真实成交后，提醒会增加真实持仓核对，包括你实际录入的持股数量，以及模拟卖出股数和真实数量的差异。

这不是券商实时同步，也未启用独立的实盘止损监控。提醒不会自动增减台账持仓；实际买卖后需要继续告诉我成交结果。

查看和维护

  • 真实持仓与成交台账：本地生成，初始为空。

  • 数据库：data/real_account/trades.sqlite3。

  • 查看记录：python -I scripts/real_positions.py show。

  • 刷新页面：python -I scripts/real_positions.py export。

  • 已确认成交由 python -I scripts/real_positions.py add 录入。

  • 误录可以使用 void --trade-id 记录ID --reason 原因 作废，保留审计记录；如果作废会导致后续卖出超过持仓，会拒绝并要求先核对关联记录。

  • 重复成交会被拦截；确有两笔完全相同成交时，使用各自唯一的 --trade-id。

  • 真实数据库及真实持仓 Markdown/HTML 已排除在 Git 提交之外。请另行备份本地数据库。

python -I scripts/real_positions.py add --side BUY --symbol 600000 --name 浦发银行 --time "2026-11-13 14:50" --price 10 --amount 10000 --fee 5

上面的命令只是示例，不会执行。--amount 默认指不含费用的成交额；若是含费用的买入支出或卖出到账额，加 --amount-includes-fees 并提供 --fee。金额、价格和股数不一致时必须核对，不会擅自四舍五入股数。
