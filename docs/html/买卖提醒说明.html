微信买卖提醒

提醒时间与渠道

  • 渠道：已配置的 PushPlus 个人微信，不推送群组。

  • 收盘信号任务：QuantBreadthDaily，北京时间周一至周五 20:00 检查收盘行情。

  • 午间复核任务：QuantMiddayCheck，周一至周五 11:35 检查次日清单的执行状态。

  • 仅有买卖或调仓复核信号时推送；无信号时只保存日报。

  • 电脑需开机且能够联网；本地计划任务不是云端常驻服务。

  • 当前数据源无法区分休市与数据更新延迟：当日无行情时跳过发送并记录日志；行情不完整时不发送交易提醒。

提醒内容

  • 买入：调仓信号产生后，列出预计增持的股票、股数、信号日收盘参考价。

  • 卖出：列出调仓减持、清仓或个股止损的股票和股数。

  • 涨停过滤：信号日收盘涨停的新建仓不列入买入，并在提醒中单独列出“未买入（信号日收盘涨停）”。下一交易日若收盘涨停，回测中的建仓/加仓也不成交。

  • 已持有且仍入选的股票不会因为涨停被强制卖出。

  • 清单先展示卖出，再展示买入，便于核对资金。

  • 信号直接读取模拟回测引擎的待执行状态；广度低于门槛不会在非调仓日单独触发清仓。

  • 同一天同类提醒成功提交推送后不会重复发送；失败不记录为成功，可重试。

时间与持仓口径

提醒是收盘后生成的下一交易日操作清单。现有回测使用下一交易日收盘价模拟成交，并未设定盘中某分钟自动下单。

涨停股在收盘时通常买不到，尤其是一字板；提醒把这类标的从买入清单中剔除，不会建议追涨停。跌停无法卖出仍未建模，止损提醒遇到连续跌停时可能无法按参考价成交。

清单基于策略模拟盘，不是券商真实持仓。股数按信号日收盘参考价和当前模拟资产估算；下一交易日价格变化可能改变股数、手续费和可执行性。执行前需自行核对实际持仓与资金，参考价不保证成交。

现在支持 手工真实持仓台账。录入实际成交后，个人微信提醒会附上真实持仓数量和模拟买卖清单的核对信息；不自动把模拟买卖写入真实台账，也不会据此声称已读取券商账户或实盘现金。

个股止损沿用引擎口径：非调仓日收盘时比较移动平均持仓成本，触发后列入下一交易日卖出提醒；不是盘中实时止损监控。

午间执行复核

  • 时间：周一至周五 11:35（上午 11:30 收盘后），Windows 任务名 QuantMiddayCheck。

  • 读取前一晚 output/breadth_latest.json 的 trade_alert，用腾讯实时行情检查计划买卖标的。

  • 买入：涨停封板或涨停未封死 → 跳过；停牌/无行情 → 不执行；跌停 → 标记“可买但风险高”；其余 → 可买入。

  • 卖出：跌停 → 延后；涨停 → 可卖出；停牌/无行情 → 无法卖出；其余 → 可卖出。

  • 只在有买卖清单时生成执行建议并推送；无清单、休市或行情不是当天的，不生成建议、不推送。

  • A 股 11:30–13:00 休市，午间不能成交；复核结果用于 13:00 开盘后的手动执行，不自动下单。

  • 现价为 11:30 行情，13:00 后可能变化，下单前需再次核对。

  • 午间复核只调整执行，不改变 20:00 的收盘信号；实际成交价与回测的“次日收盘价”口径可能不同。

文件与命令

  • 任务入口：scripts/run_daily_breadth.ps1

  • 提醒生成：python -I scripts/daily_breadth_report.py --signals-only

  • 生成并发送：python -I scripts/daily_breadth_report.py --signals-only --send

  • 历史回放：python -I scripts/daily_breadth_report.py --no-update --date 2026-11-13 --signals-only；历史回放禁止带 --send。

  • 午间复核只生成：python -I scripts/midday_check.py

  • 午间复核生成并推送：python -I scripts/midday_check.py --send

  • 午间复核强制重发：加 --force

  • 注册午间任务：powershell -NoProfile -ExecutionPolicy Bypass -File scripts/register_midday_task.ps1

  • 最新结果：output/breadth_latest.json 中的 trade_alert。

  • 推送去重：output/last_trade_signal_push.json（收盘提醒）、output/last_midday_push.json（午间复核）。

  • 日志：output/logs/daily_breadth_YYYY-MM-DD.log、output/logs/midday_check_YYYY-MM-DD.log。

  • 报告：docs/md/市场广度日报/ 和 docs/html/市场广度日报/；午间复核在 docs/md/午间复核/ 和 docs/html/午间复核/。

  • 午间结构化结果：output/midday_check_YYYY-MM-DD.json。

本功能仅发送提醒，不会连接券商提交订单。
