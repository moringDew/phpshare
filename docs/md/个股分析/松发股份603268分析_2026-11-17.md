# 松发股份（603268）分析报告

> 数据截至 2026-11-17 收盘｜来源：东方财富行情/资金/F10/公告/研报｜仅供研究参考，不构成投资建议

## 一、结论速览

- **公司性质**：恒力系把**恒力重工**装入原陶瓷上市公司松发股份，现已更名"恒力船舶重工"，是 A 股稀缺的**民营造船龙头**。
- **基本面**：2026 前三季营收 377.7 亿（+221%）、净利 66.7 亿（+425%），Q3 单季净利率 21.5%，经营现金流为正且远超净利——**报表质量明显好于概念股**。
- **估值**：PE(年化) 19.3 倍不算贵，但 **PB 7.44 倍是同业（1.5–1.9 倍）的 4 倍**，溢价完全靠 46.6% 的 ROE 支撑，而这是**周期高点的 ROE**。
- **最大风险**：**2028-05-23 解禁 7.375 亿股，占总股本 72.4%**；2027-01-29 还有 4.71% 解禁。控股股东合计持股约 76%，流通盘仅 23.3%。
- **技术位置**：250 日涨幅 +615%，当前处于**高位回调后的反弹**（5 日 +11.5%），不是低位；上方 176（MA30）、185.7（MA60）是压力。
- **一句话**：好公司，但现在是"周期股盈利高点 + 高 PB + 远期巨量解禁"的组合，属于**要等位置、要控仓位**的品种，不是闭眼买的低位票。

## 二、它是怎么变成造船股的

| 事项 | 内容 |
|---|---|
| 原主业 | 广东松发陶瓷，日用陶瓷 |
| 重组 | 恒力集团将**恒力重工**注入，构成重组上市（借壳） |
| 新名称 | 2026-11 董事会/股东会通过更名为"恒力船舶重工股份有限公司" |
| 实控人 | 陈建华（恒力集团创始人） |
| 股东结构 | 苏州中坤投资 33.72%、陈建华及恒能投资等 3 家各 12.89%、恒力集团 3.67%（限售为主） |
| 员工 | 6,830 人 |
| 经营范围 | 船舶销售/制造、海洋工程装备、海上风电装备等 |

**要点**

1. **量价齐升**：营收连续翻倍，净利率从 10.8% 一路升到 21.5%，说明交付的是高价订单，规模效应显著。
2. **现金流健康**：2026 前三季每股经营现金流 +13.25 元（约 135 亿），大幅高于净利 66.7 亿，主要来自**合同负债（预收款）**——订单饱满的直接证据。
3. **高杠杆**：资产负债率 77.6%，符合造船业"预收款+应付账款"模式，但绝对水平需持续跟踪。
4. **可持续性存疑**：造船业正常净利率在 5%–10%，21.5% 是**周期高点才能出现的水平**。船价、钢价、汇率任一逆转，利润率都会回落。

- 当前流通股仅 2.33 亿股（流通市值 393 亿），**流通盘只占总股本 23%**。小流通盘解释了它 615% 的涨幅和 6%+ 的日波动。
- 2028 年 5 月是真正的"大坝开闸"——72.4% 的股份解禁，届时分流压力极大。**这是所有长线持有者必须计入的折价因素。**

**机构持仓（2026-09-30）**：287 家机构持有 46.1% 的流通股，包括全国社保 103/108 组合、中国人寿、大成/中欧/博时等公募、瓴仁私募，香港中央结算（北向）1.59%。**机构认可度明显高于普通题材股。**

**其他事件**
- 2026-11-07 回购预案，11-14 首次回购，11-11 取得回购专项贷款承诺函——公司层面在护盘。
- 2026 年员工持股计划已通过持有人会议。
- 11-05 龙虎榜：跌 7.84%，买入 4.35 亿 / 卖出 7.59 亿，**净卖出 3.24 亿**。
- 融资余额 7.35 亿，仅占流通市值 1.83%，杠杆风险低。
- 股东户数 26,152 户，户均市值 598 万——筹码集中在大户/机构手中。

## 七、多空对照

**利多**
- 真实业绩：营收 +221%、净利 +425%，Q3 净利率 21.5%，经营现金流 +135 亿。
- 订单饱满：合同负债大幅流入，民营造船效率优势。
- 机构持仓扎实：社保、险资、公募、北向。
- 回购 + 员工持股 + 更名，管理层动作积极。
- 2027 年前无大规模解禁，筹码结构稳定。
- 5 分钟/日线反弹结构未破，缩量回调健康。

**利空**
- PB 7.44 倍，是同业 4 倍，周期高点的 ROE 难以长期维持。
- 净利率 21.5% 远超行业正常水平，均值回归风险大。
- 2028-05 解禁 72.4%，远期供给压力巨大。
- 流通盘仅 23%，大资金进出困难，波动剧烈。
- 控股股东持股 76%，治理与关联交易需关注。
- 250 日 +615%，涨幅已大幅透支；周线 MACD 仍为绿柱。
- 龙虎榜显示 11-05 有大额资金出逃。

- 数据来自公开接口，财务为 2026 三季报（未审计）；造船业订单与交付节奏存在季度波动。
