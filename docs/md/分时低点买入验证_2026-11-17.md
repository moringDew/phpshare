# 分时低点买入验证：等反弹有优势吗？

> 2026-11-17 研究。使用同一批预先选定的股票，比较三种买入时点。

## 结论

**等低点反弹后买入，在这个样本里比收盘买略好，但比开盘买差。** 平均每笔持有期净收益较收盘买高 **0.12 个百分点**，较开盘买低 **0.24 个百分点**。优势主要来自两次调仓，现有证据不足以把这套规则用于默认买入，也不能据此上调预期年化。

## 可执行的规则

1. 前一交易日收盘，用已冻结的低波动选股规则生成次日买入名单，不用当天分时涨跌决定选哪些股票。
2. 从开盘开始，按已走完的 15 分钟 K 线更新当日低点。最早 10:00 检查：低点距昨收至少下跌 1%，该根收盘价已从低点反弹至少 0.6%，且高于前一根收盘。
3. 下一根 K 线开盘价不超过信号收盘价的 100.5%、也未接近涨跌停时，按该开盘价模拟成交。没有成交可以继续观察，最晚 14:30 发信号。全天没有触发成交时按预定规则在收盘买入。

例如，昨收 10 元，盘中最低到 9.85 元；只有分时 K 线收盘回到约 9.91 元或以上且高于上一根收盘，才会发出信号。之后用下一根的开盘价模拟成交。回测不会把已经过去的 9.85 元当作成交价。类似的历史模拟要区分出信号的 K 线和后续可以成交的价格，参见 [TradingView 回测成交说明](https://www.tradingview.com/pine-script-docs/concepts/strategies/)。

## 同股、同卖出日对照

新浪 15 分钟数据配对成功 165 / 165 笔，涉及 57 只股票、11 个买入日。买入日覆盖 2026-08-17 至 2026-11-03；最后一笔模拟卖出为 11-10。三种买入方法统一在买入日之后第 5 个交易日收盘卖出，单边成本均为 0.20%。不做当日买卖。每笔等权比较，净收益包含买卖费用。

| 检验 | 结果 |
|---|---:|
| 分时反弹触发成交 | 65 / 165（39.4%） |
| 已触发时，买价平均比当天收盘低 | 0.30% |
| 每笔持有期净收益比收盘买高 | +0.12 个百分点 |
| 每笔持有期净收益比开盘买高 | −0.24 个百分点 |
| 对每笔分时成交额外扣 0.10 个百分点后，相对收盘优势 | +0.08 个百分点 |
| 无信号时改为空仓，相对全部收盘买 | +0.10 个百分点 |
| 分时反弹相对收盘买占优的买入日 | 7 / 11 |
| 8–9 月，相对收盘买 | +0.003 个百分点 |
| 10–11 月，相对收盘买 | +0.324 个百分点 |
| 去掉表现最好的两个买入日，相对收盘买 | −0.003 个百分点 |

开盘买入是这里的简单对照。反弹条件发生时，价格可能已经比开盘更高；即便盘中曾跌得很低，也不代表能在确认之后买得更便宜。

## 使用边界

本实验只隔离买入时点。每个调仓日把 15 只候选视为独立的买入机会，包含重复入选的股票；没有把它们假设成实际账户的新增委托。买入次数、仓位、真实滑点和成交队列都会影响组合表现。接近涨跌停用日变动估算，分时成交价也不是实盘可成交保证。11 个独立买入日太少，不能把逐笔收益差复利成年化。

如果继续验证，建议模拟盘并排记录开盘买、收盘买和反弹买的同一批委托，优先比较 **相对开盘买的扣费收益**，并保留没触发和没成交的样本。现有交易提醒、下单和真实持仓未接入这套规则。

复跑：`python scripts/research_intraday_entry.py` 使用本地分时缓存，添加 `--fetch` 可从新浪获取公开行情。逐笔对照和成本压力结果写入 `output/intraday_entry.json`。
