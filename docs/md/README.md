# 知衡 · A 股量化交易平台

当前已开始第一阶段开发，完成可运行的 A 股多因子选股与历史回测核心。

阅读文档统一存放在 `docs/md/`（Markdown 源文件）和 `docs/html/`（离线 HTML），两边使用对应子目录。以下命令均在项目根目录运行。日报、交割单和优化报告生成脚本会同步输出两种格式。

- [交割历史单（浏览器阅读版）](../html/交割历史单.html)

浏览器阅读策略汇总时，请打开 `docs/html/策略汇总.html`。修改 `docs/md/策略汇总.md` 后，运行 `python scripts/render_strategy_summary.py` 更新离线 HTML 版本。

交割历史单的离线 HTML 可运行 `python scripts/render_strategy_summary.py docs/md/交割历史单.md` 更新。

批量更新所有文档的离线 HTML 和目录：`python scripts/render_strategy_summary.py --all`。

当前选股模块采用动量、趋势、低波动、低回撤、流动性和可选财务质量因子，并通过配置检查年化收益、最大回撤和调仓周期胜率。历史门槛仅用于研发验收，不构成未来收益保证。
